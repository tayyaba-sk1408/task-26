# Day 26 Internship Task - Signup Form Validation

## Project Overview

A responsive signup form developed using HTML5, CSS3, and JavaScript. It validates the user's name, email address, password, and acceptance of terms with inline feedback.

## Features

- Name, email, and password fields
- Inline validation messages
- Email format validation using a regular expression
- Password minimum length and complexity checks
- Live password strength indicator
- Show/hide password functionality
- Terms acceptance validation
- Form submission validation
- Success message after valid submission
- Responsive dark UI with gradient accents

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Create a folder named `Day_26_Signup_Form`.
2. Create the four files shown in the project structure.
3. Copy the appropriate code into each file.
4. Keep all files in the same folder.
5. Open `index.html` in a web browser.
6. Enter your details and test the validation.

No installation, database, or backend server is required.

## Validation Rules

- Full name must contain at least two characters.
- Email must follow a valid email format.
- Password must contain at least eight characters.
- Password must include uppercase letters, lowercase letters, and a number.
- The terms checkbox must be selected before submission.

## Learning Outcomes

This project provides practice with HTML forms, CSS styling, JavaScript event handling, regular expressions, conditional logic, DOM manipulation, and password strength calculation.
